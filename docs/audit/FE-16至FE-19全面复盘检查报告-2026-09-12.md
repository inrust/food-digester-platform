### 2.1 M-03 关闭证据：Locale 格式化

- `LocaleValue` 统一提供数字、百分比和单位格式化，使用当前语言对应的 `Intl.NumberFormat` locale；
- 支持的单位使用本地化单位名称，不支持或协议专用单位保留单位原文，但数字仍按 locale 格式化；
- ESG 保留业务规定的小数位精度，同时随 zh-CN/en 切换；
- 版本号、设备 ID、协议枚举和用户输入数据继续按业务边界保留原文，不作为普通数字本地化。

### 2.2 M-04 关闭证据：布局与裁切

- 移除 `body`、`.page-content` 和移动端 breadcrumb 上会掩盖横向问题的 `overflow:hidden`；
- Chromium 对 22 个生产路由执行 zh-CN/en × 375/768/1440px，共 132 个路由/语言/视口组合；
- 每个组合同时检查 document 实际宽度，以及具有直接可见文本的元素是否被 `overflow:hidden/clip` 裁切；
- `CursorTable` 继续作为显式横向滚动容器，不把宽表滚动误判为页面溢出。

### 2.3 L-02 关闭证据：耗材列表分页

- OpenAPI 新增通用 `Limit`、`Cursor` 参数，成功响应改用 `PageMeta`；
- 服务端校验 limit 和不透明 cursor，非法值失败关闭为 400；
- 服务端按 deviceId 升序分批扫描，在应用 connectivity/耗材阈值等筛选后生成稳定键集页，避免固定 200 条截断和一次加载完整设备集；
- 前端 API 返回 `items + nextCursor`，controller 维护当前游标及上一页栈；
- 单元测试覆盖两页往返、非法 cursor/limit，Chromium 覆盖真实组合根上一页/下一页。
