## 2. 基础设施与权限闭环

新增独立 `fdp-{env}-device-api-handler` Lambda 与 `fdp-{env}-device-api-role`，Device API Gateway 不再复用 Admin `ApiFn`。Device Lambda 获得数据库 Secret 读取、证书包 KMS 数据面及证书轮换所需 IoT 权限；证书包 KMS Key Policy 同步加入确定性的 Device API Role ARN。CDK 测试同时锁定：

1. Device API 与 Admin/Onboarding Lambda 集成隔离；
2. Device Lambda 使用真实 CDK asset，不得回退到内联 501 占位实现；
3. 10 个 Lambda 使用 10 个独立执行角色；
4. Device Lambda 必需环境变量和 KMS principal 完整。
