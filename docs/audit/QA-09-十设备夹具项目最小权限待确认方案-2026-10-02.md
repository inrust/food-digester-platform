# QA-09 十设备夹具项目最小权限待确认方案

现有 esgiot-infra 创建 `fdp-test-qa09-ten-device-fixtures` 被 AWS 拒绝：缺少 `iam:PassRole`，目标为 `arn:aws:iam::065986019555:role/fdp-test-migration-runner-role`。esgiot-dev 则缺少 `codebuild:CreateProject`。这是 AWS IAM 拒绝，非自动审批系统拒绝。

待授权动作：由有权限的管理员在 IAM Identity Center 的 FDP-InfraSetup permission set 临时增加下面的单一 Statement，重新 provision 到测试账号，完成验收后撤销。仅允许指定角色交给 CodeBuild；不得增加通配角色、数据库公网入口、长期 Access Key 或生产权限。若已有 Boundary/SCP 仍拒绝，保留拒绝证据，不自动扩大权限。

```json
{
  "Effect": "Allow",
  "Action": "iam:PassRole",
  "Resource": "arn:aws:iam::065986019555:role/fdp-test-migration-runner-role",
  "Condition": {
    "StringEquals": {"iam:PassedToService": "codebuild.amazonaws.com"},
    "DateLessThan": {"aws:CurrentTime": "2026-10-03T00:00:00Z"}
  }
}
```

替代方案：管理员创建同名专用 CodeBuild 项目并绑定现有角色/VPC。项目配置模板见 `evidence/qa-09-ten-device-2026-10-02.json.seed-0.json.preparation.json` 的 project 字段；其中首次 Customer 已软删除，旧 buildspec 不得启动。执行器将使用新前缀和新 Customer 更新固定源码后启动；更新时保持 serviceRole 不变。创建项目不自动启动 Build。

新项目只执行仓库固定的十设备 seed、只读 observe、精确 ID cleanup。新旧设备和证书摘要核验、事务回滚、PROCESSING Job 禁删、源码与 Build 回执绑定均已实现测试。不得改造原 Migration Runner 或只读项目执行写入，也不通过 CloudFormation 绕过当前授权边界。完成后删除本轮专用项目并保留日志回执；历史加密快照、设备和证书保留。

当前只做方案准备，尚未更改 IAM 权限、创建专用项目或写入设备库存。首次真实身份与 Customer 已清理；独立只读查询另行记录。
