## 发现与修复

- 新测试验证缺少 exp 的已签名 JWT 被接受，已增加必需声明；同时约束 auth_time 为正安全整数及当前时间/时钟容差，统一失败关闭401。
- 原 Logger 对未知字段中的裸 JWT/签名 URL 及部分凭据键未遮蔽；独立扫描首次报告13项发现。已扩展字段和值形态脱敏，并由四级 Logger、Error、Trace JSON 与落库审计回归验证0发现。
- 审计 before/after 载荷补充签名 URL 脱敏；完整回归发现前端字段镜像未同步，已同步并保留既有 parity 约束。

SQL 片段作为允许字符的普通名称被安全存储属于参数化查询语义，并不声称所有恶意文本都必须400。有效 JWT 复用未被禁止；非法重放与一次性凭证消费另行验证。扫描器避免把测试标题中的普通“Bearer JWT”标签误当凭据，实际 JWT、私钥、签名 URL、敏感字段和 canary 的负测试仍拒绝。
