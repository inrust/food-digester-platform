## 2. 证书生命周期与失败语义

Rotate 的恢复边界现在由持久化状态决定：

1. 轮换记录尚未领取且没有证书包，视为从未成功封包，可将失败的新证标记撤销后重新签发；
2. 一次性包已被预留但提交确认尚未完成时，按“不确定是否泄露”失败关闭：撤销 IoT 新证、销毁未确认包并有界重签；
3. 响应提交成功后包已清除且 `claimedAt` 已记录，此时新证保持 ACTIVE 并等待首个 Heartbeat，重复请求返回确定冲突，不再进入撤销/重签循环。

退役完成仍由数据库条件更新保障单一胜者。设备确认、管理员强制完成和 72 小时超时 evaluator 竞争时，只有一个完成路径能够落库、撤销证书并写入对应审计动作。

## 3. 基础设施与最小权限

- `RetirementTimeoutFn` 使用真实 asset 和独立入口，只注入数据库 Secret、退役批量上限等必需配置，并获得数据库 Secret 读取权限；EventBridge 规则按 5 分钟频率调度。
- `OutboxPublisherFn` 从占位实现切换为真实 asset，保留归档 SQS 发布能力，并新增 IoT `DescribeEndpoint` 与 `topic/bnx/device/*/notification` 的发布权限；没有扩大到设备上行、命令或 ACK Topic。
- IoT 发布使用 AWS SDK Data Plane `PublishCommand`，UTF-8 JSON、QoS 1；数据库 Outbox 只在远端发送成功后变为 PUBLISHED，失败继续使用既有重试/终止策略。
