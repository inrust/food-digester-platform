## 发现与修正

OTA 下载契约声明 307 的 Location、Cache-Control=no-store，未声明 JSON content；实际 Handler 曾额外返回 `{expiresAt}`。已修正为 `body: undefined`，Device Lambda 适配器将其序列化为空字符串。回归用实际 Handler + PGlite 下载 grant + Lambda 适配器验证 307、响应头、空正文及重复消费 409。修正服务以符合现有契约，不增加协议字段/版本或新业务决策。

起始独立测试遇到近期 CSR 提交后的 Prisma Client 未重新生成，已运行 `pnpm --filter @fdp/database generate` 的等效本地 Prisma 命令恢复。早期直接 cloud-api tsc 还引用旧共享包 dist；完整 `pnpm verify` 按 Turbo 依赖关系重新构建，最终 typecheck/build 均通过。没有为了测试通过修改业务契约。

前版快照来自 QA-01 提交 `d93cafb9b2f03ca14a5d3dafc3555e6692cd7232` 的 0.11.0，当前快照来自 CSR 提交 `1af58ee` 的 0.12.0。9 项已有破坏性差异包括新增 CSR 必填、删除 privateKey、证书 chain/双通道状态以及 APPROVED 分支变化；分别按 DEC-026@1.0.0 / DEC-003@1.1.0 追溯。**不声称 REST 0.11.0 消费端完全兼容 0.12.0**。
