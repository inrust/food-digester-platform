## 变更

- Gateway 限定字段访问日志与 API 完成日志关联 requestId、extendedRequestId、integrationRequestId、Lambda requestId、operationId；异常记 UNHANDLED，日志失败不改变业务结果。固定字段、ID 校验及 redacting logger 防止 Token/body/query 泄漏。独立 KMS 日志组保留 7 天。
- 18 个 DB Lambda 的并发/池上限从单一预算表生成。即时阶段稳态 44，运维/重叠预留 18，共 62≤70；Admin 并发 12、Publisher 并发 2，其余函数按预算配置。pool1 仅在阶段开关下启用，拒绝非法池参数。
- Command、审计、唯一 Outbox 在同一事务提交，提交后 SQS 立即通知；发送失败由分钟扫描补偿。共享持久租约阻止通知/扫描并发抢占，过期恢复、旧持有者保护和 ACK 终态保护保留。SQS partial failure 重试；非法/终态通知不发 MQTT；终态仅清理空闲或过期租约。
- 新增受控 AWS PostgreSQL 单连接只读探针。夹具清理增加精确自有 Command/业务 Outbox，保留非本轮事件；新范围 18 张表不改写历史 17 表回执。
- 分阶段开关默认 baseline，限定 Gateway 日志 Boundary 补丁仅是待实施材料；没有修改线上 IAM、Lambda、Gateway、并发或共享数据库数据；仅更新既有受控夹具 CodeBuild 项目的固定探针源码并启动一次只读 Build。
