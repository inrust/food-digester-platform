## 本轮 A5 执行和证据

此前已关闭的真实 Operator 非空 Replay、唯一生产/消费关联、同轮非空去重三项证据继续保留，见[上一轮摘要](evidence/qa-09-a2-a5-2026-10-13/a5-closeout-summary.json)。本轮核验相关应用工件兼容性，避免重复 Replay 和全量业务测试。

本轮使用显式 remaining-only 模式：十张真实证书、MQTT 和 mTLS 仅作为自有夹具准备；只补发单设备 telemetry/alarm/event/tamper 四条业务消息。检查真实 receipt、信号业务行、ARCHIVE outbox、SQS 消费请求和固定 S3 版本的压缩字节及 Manifest。不会把 MQTT PUBACK 单独当作业务完成。

坏消息隔离使用部署后的 Archive Lambda 直接调用：合法消息、重复合法消息、坏 JSON 和坏归档信封混批；验证只退回两个坏记录、合法消息仅生成一个逻辑对象。记录 ID 明确标为直接调用夹具，**不作为真实 SQS 投递、重试或 DLQ 证据**。

Summary 只等待原 `rate(1 hour)` 自然调度；以 EventBridge eventId、Lambda requestId、own device/customer、日报内容摘要绑定同次执行和真实数据库行，不手工调用 Summary，不直接种日报行。

最终结果、版本、清理和脱敏证据将在本轮目标补验结束后封存。完整原始回执保存在本地 `build/qa09-private-a5-minimum-20261013/`，公开仓库仅含代码和脱敏摘要。
