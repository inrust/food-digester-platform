# DEC-004 Device User 密码验证格式

DEC-004 已由业务方确认并冻结为 `1.0.0`。正式冻结记录见 [DEC-004-freeze-1.0.0.md](../../contracts/decisions/changes/DEC-004-freeze-1.0.0.md)。

## 冻结值

| 项 | 值 |
|---|---|
| KDF | Argon2id v=19 |
| 参数 | `memoryKib=32768`、`iterations=3`、`parallelism=1` |
| Salt / Hash | 每用户独立随机 Salt 16 字节；Hash 32 字节 |
| 线协议 | Sync 的 `passwordHash` 字段，PHC 字符串 |
| 性能验收 | 最低配置设备单次验证目标约 250～500 ms |

验证材料仅供设备本地登录，不得复用 Cognito 或云端用户密码 Hash，只能经 Unified Device Sync 下发；查询 API、日志和审计不得返回 PHC 字符串。

## 可执行契约与生产实现

- [device-user-verifier-policy.json](../../contracts/security/device-user-verifier-policy.json) 已提供冻结参数，`pendingParameters=[]`。
- [device-sync-api.json](../../contracts/rest/device-sync-api.json) 已约束 `passwordHash` 为 Argon2id PHC 字符串。
- [verifier.ts](../../apps/cloud-api/src/admin/device-user/verifier.ts) 已实现生产 Argon2id PHC 生成/验证、严格参数校验、随机 salt 和脱敏防线。
- Device User 管理写接口只接收 `writeOnly password` 并在服务端派生；数据库新写路径仅保存 `password_hash`；Sync 输出单一 `passwordHash` 字段。
- 固定测试向量：password=`correct horse battery staple`、salt(hex)=`000102030405060708090a0b0c0d0e0f`、PHC=`$argon2id$v=19$m=32768,t=3,p=1$AAECAwQFBgcICQoLDA0ODw$u+TOcl2LGub4w/cLIdrGdoG/cbU//EuAXDXm+qRHfqs`。
- 仍需由最低配置真实设备提供约 250～500 ms 性能验收收据；该项不影响线协议与服务端实现一致性结论。
