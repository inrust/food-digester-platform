## 分界的可执行范围

本轮仅新增测试目录中的探针、真实Prisma/受控pg实验及严格离线校验器。探针默认关闭，不从database包导出；应用、Admin hook、环境变量、Infra、workflow及现有开关均未修改。公开Prisma query extension、transaction adapter queryRaw及pg调用是测试接缝，不访问compiler/runtime私有API，不缓存SQL或结果。不能把离线helper称为已部署观测或优化候选。

| 原窗口 | 离线公开标记和子段 | 解释边界 |
| --- | --- | --- |
| after-queue | 内层query extension两次显式让步后进入 → 受控工作完成 → query(args)返回 → transaction adapter进入 | 最后一个子段包含惰性模型准备/调度；不等于compiler-only。原检查点至内层恢复之间仍有未细分余量 |
| driver-query | adapter进入 → 同步调用返回 → Promise恢复 → adapter返回；嵌套pg进入 → 调用返回 → 受控结果就绪 | 同步提交、等待/恢复、结果转换分开；pg不是数据库服务器计时，不能将嵌套pg与adapter总段相加 |
| result | adapter返回 → 内层extension恢复 → extension返回 → 调用方恢复 → load返回 | 含Prisma结果传递、观察者、Promise调度及调用方工作；adapter返回与原driver最终结算间存在观察成本，严格保留5ms容差而不声称完全同边界 |

18个固定标记保存单调微秒、墙钟毫秒、进程user/system CPU累计值和限定requestId；子段使用相邻差值。PROCESS_ALL_THREADS包括后台线程，CPU可超过wall；等待段CPU不能归属于单个编译线程，wall减CPU不能算网络等待。整数0ms只表示量化。新离线校验器还运行原split/detail/await三个严格证明，原容差5ms不变；标记必须唯一、按序、归属于同一请求、落在父阶段，缺失不补零。失败仅保留真实前缀，不能变成完整分界；update/audit失败时首读分界可以完整，但事务整体仍是EXPECTED_FAILURE。

**实验有意加入两次显式Promise让步及async端口包装，两组相同，另有原异步调用调度。它不是目标等价链路。** 下一步运行时接线不能直接复制这些强制让步或全局测试mock，也不能承诺原Promise身份不变。默认关闭仅指离线探针及既有生产默认状态；尚无新的运行时开启入口。

执行器要求目录不存在，拒绝部分/失败目录重放。固定16个新Node进程、串行、每进程45秒、pool1、网络0、数据库服务器0、目标夹具0。每个成功组合做首次/后续共3个原事务，失败组合只1个；不扩样、自动重试或根据结果挑选输入。真实Prisma/adapter包与schema、lockfile、执行器/探针字节哈希写入matrix。受控pg租约/mock只存在于单测试进程；Socket.connect硬拒绝且计数必须0，最后恢复所有mock/环境变量。

组合：off/on零注入；after-queue CPU20ms/等待30ms；pg同步提交CPU20ms/等待30ms；受控fields访问CPU20ms；adapter恢复CPU20ms；extension恢复CPU20ms；调用方CPU20ms；await/pg/fields/result/update/audit六处失败。注入仅影响首次合同读取，不泄漏到读回。账号固定原生读取，合同固定ORM，原事务中继续version updateMany、findFirst读回、auditLog.create。审计仅返回id，明确是离线子集；无真实数据库约束、网络、数据库计划或完整service延迟证明。直接extension异常保持对象身份，Prisma包装driver异常时校验原40001 code，不要求跨引擎对象身份。

校验包括成本落点下界（注入−2ms）、父段包含、全标记/请求/CPU/墙钟/操作数、52次租约释放/16个pool释放、原回滚/无重试。off必须无新标记/详细子段。旧目标回执或错误声明targetEquivalent/编译/服务器/P95为true均被拒绝。
