## 冻结值

- 归属层级固定为 Customer → Site → Device。
- Region/Subregion 是 Site 的可筛选属性，不是独立实体。
- Device 只保存 `siteId`；地域经 Site 派生，禁止冗余地域真值。

`pendingParameters=[]`，后续变更必须提升 DEC 与策略版本，不得静默修改消费者行为。
