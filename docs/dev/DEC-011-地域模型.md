# DEC-011 Region/Subregion/Site 模型

DEC-011 是协议冻结门禁决策（当前 `pending`，登记版本 `0.2.0`）。按《管理后台开发任务清单》§4 末段，本任务把暂定值落地为数据驱动、可整体替换的策略扩展点。**决策本身未冻结，冻结必须经业务方批准人按 [decision-change-template.md](../contracts/decisions/decision-change-template.md) 执行。**

## 暂定值（provisional）

> Region/Subregion 为 Site 可筛选属性；设备只关联 Site，不直接保存重复地域真值。

全部为定性规则，已可直接执行：

| 策略面 | 暂定结论 | 消费任务 |
|---|---|---|
| 归属层级 | Customer → Site → Device；设备仅经 `siteId` 关联，禁止直连 Customer 或地域实体 | DB-01、BE-CUS-02、BE-DEV-01 |
| 地域属性 | Region/Subregion 是 Site 的可筛选属性，非独立实体 | DB-01、BE-CUS-02、FE-05、FE-06 |
| 设备真值 | 设备行禁止冗余存储 region/subregion；设备地域信息经 Site 派生查询 | DB-01、BE-DEV-01、FE-05、FE-06 |

`pendingParameters` 为空：本决策无待定参数，冻结时若暂定值不变仅需改状态。

## 使用约束

1. DB-01 的 Device 表不得包含 region/subregion 列；地域筛选一律经 Site 关联查询；
2. FE-05/FE-06 的地域筛选器数据源为 Site 属性的去重集合，不构建设备级地域索引；
3. 若未来 Region 实体化（独立表），属冻结变更，需迁移 DB-01 Schema 与查询契约。

## 冻结升级路径

1. 业务方批准 DEC-011（登记升至 `>= 1.0.0`、`frozen`）；
2. 暂定值未变化：`status` 改 `frozen`，提升 `policyVersion` 即可。
