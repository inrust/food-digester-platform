## 已验证的运行时接缝

新增 `FDP_QA09_CONTRACT_PUBLIC_BOUNDARIES`，默认false；只有test/pool1/engine=true/preconnect=true/detail=true才可开启。工厂、Admin初始化、Infra context、仅ApiFn环境、workflow/resolver、实际配置和matched manifest均接线。push固定false；手动输入 `contract_public_boundaries` 默认false，R0/R1需显式同时true。合同原生读取候选仍无运行时开关，保持false；本次仅增加观测。

| 父段 | 新子段 | 公开边界及限制 |
| --- | --- | --- |
| contract-load-driver-query | driver-submit / driver-await | adapter调用进入→同步返回→既有await结算；后段含等待、adapter处理与调度 |
| contract-load-driver-pg | pg-submit / pg-await | 原pg query进入→原调用返回→原Promise/回调结算；不是数据库服务器计时 |
| contract-load-result | result-to-model / result-after-model | adapter结算→既有客户端准备包装器的await恢复→原load结算；后段含观察成本及Prisma返回/调用方工作 |

完整阶段名均以 `contract-load-` 开头。同步返回边界分别为ADAPTER_CALL_RETURNED、PG_CALL_RETURNED；既有扩展包装器恢复边界为MODEL_EXTENSION_RESUMED。这不是Prisma compiler内部或严格“模型完成”点。

`query(args)`实际返回惰性PrismaPromise，不能另加 `.then` 读取结果。本实现保持同步submission原返回值，复用原 `observeDatabaseClientPreparation` 的一次await恢复通知；不额外消费PrismaPromise、不增加await/强制让步，不复制上轮测试的两次显式Promise让步或async端口包装。已有detail模式的观察性queueMicrotask保持原义，不await它。pg原生Promise仍由既有观察器监听，原Promise身份、回调receiver/参数/返回值及异常对象保持，释放恢复原描述符。

公开API没有可稳定细分after-queue内部的更细compiler接缝，继续标记 `UNRESOLVED_NO_STABLE_COMPILER_SEAM`。禁止私有compiler hook、推断零段或放宽5ms容差。新三组子段共享父阶段原始时间/CPU分界，精确一次driver返回/pg返回/模型恢复，原事务且一个模型入口/driver/pg/结算；缺失、重复、外来ID、提前结算、失败、非法CPU均拒绝。同步pg回调先结算时保留原业务回调，但不合成await子段，不能满足新Gate。晚回调不再发日志。

CPU为PROCESS_ALL_THREADS，含其他线程；0ms是量化值。driver和pg阶段嵌套，不相加；CPU不能换算网络等待。日志会扰动时序，离线off/on不能证明零开销、因果收益或目标P95。
