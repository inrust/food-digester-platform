# License 云端自动激活

2026-11-11，依据本轮用户确认的 DEC-027@1.0.0 实施。现有 License 激活按钮同时完成设备激活，管理员按已有创建、签发和激活流程操作。

License 状态变更、设备生命周期和运行状态、状态历史、审计及通知在同一事务提交。Assigned/Licensed 设备直接进入 Active。事务按设备、License 顺序锁定，沿用预览权威写入口失效协议，失败时整体回滚。

为兼容已经激活 License 但设备停在 Assigned/Licensed 的记录，普通 Sync 在云端幂等补齐。依据是当前生效的 Active/ExpiringSoon/Renewed License、有效期、签名和同客户/同站点有效分配。设备原来已挂起、退役、未分配或运行状态已挂起/退役时保留原状态。Issued License 仍需现有管理员激活操作。

Sync 请求和响应结构兼容，旧 licenseConfirmation 字段继续校验，但不参与状态迁移。激活审计记录实际云端操作者及来源；App 继续普通同步和本地 License 检查。

设备预览白名单沿用独立开关。云端激活后，设备具备申请媒体上传会话的生命周期条件；实时预览仍由目标设备的开通状态和查看租约控制。

本地验证已通过工作区 21 项类型任务、319 项契约测试、1694 项脚本测试、6 个相关业务测试文件的 169 项用例，以及最终状态机/激活专项的 121 项用例。OpenAPI、格式、lint、模块边界、秘密扫描和日志脱敏检查通过。首次回归发现旧历史候选测试读取了当前决策文件，已将历史协议测试放到冻结源码夹具中，正式校验器的源码漂移拒绝规则保留。

本批无需数据库结构迁移。测试环境部署和第三方真实传图结果在对应发布运行及联调记录中核验。
