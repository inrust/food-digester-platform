# DEC-026 设备证书 CSR 轮换与双通道确认

版本 1.0.0，2026-10-01 用户批准实施。保持 DEC-017 首 Heartbeat 激活和现有 IoT RegisterCertificateWithoutCA 注册；新增完整公开 CA chain、受控 Device ID 身份与真实 X509 元数据。REST 根据登记 PEM 指纹、ACTIVE、有效期、设备归属和生命周期鉴权。

设备本地生成新密钥和 CSR，轮换不返回私钥。新旧证在原各自有效期内并行，新证双通道确认窗口最长 24 小时。合法 MQTT Heartbeat 与成功 REST Sync 均使用新证，任意顺序完成后事务撤销旧证并登记可重试 AWS INACTIVE 意图；截止未完成时拒绝并撤销新证，旧证不受影响。独立记录四项验证/确认时间，未知历史证据保持 null。

公钥所有权永久绑定设备，跨设备复用拒绝；同设备申请恢复允许相同申请密钥，轮换必须换新密钥。完整请求/响应与错误见 [API](../api/README.md)，迁移及真实环境验收前置条件见 [实施验收](../audit/设备证书CSR轮换与双通道确认实施验收-2026-10-01.md)。
