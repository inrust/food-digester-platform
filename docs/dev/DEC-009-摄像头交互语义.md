# DEC-009 摄像头交互语义

2026-11-06 用户确认方案后升级为 2.0.0。正式记录见 [升级记录](../../contracts/decisions/changes/DEC-009-upgrade-2.0.0.md)。

归档媒体入口保留最新授权 Media 和手动刷新方式。live-image-v1 设备本地显式启用并进入服务端设备白名单后，使用 REST 租约和 Base64 预览。缺省关闭，现有设备无需增加调用。配置来源独立于四字段 Configuration V1，设备本地配置由软件发布或现场配置写入，服务端白名单由后续部署配置提供，禁止客户端自报 customerId 或以 JSON 声明替代服务端准入。

预览参数为设备查询 5000ms、上传和页面读取各 2000ms、租约 30s、续租 10s、帧 10s、去重摘要 15s、单设备最多 16 个查看者。归档每条事件或 ACTIVE 告警一张图片，以原消息 ID 关联。完整边界见 [接口设计](../api/device-image-interface-design.md)。

[JSON 策略](../../contracts/domain/camera-interaction-policy.json)、[TS 策略](../../contracts/domain/camera-interaction-policy.ts)、[Schema](../../contracts/domain/camera-interaction-policy.schema.json) 及 [消费者追踪](../../contracts/prototype-traceability.yaml) 同步维护。原查询函数继续表达归档入口策略，新增 liveImage 策略专门用于后续预览消费者。
