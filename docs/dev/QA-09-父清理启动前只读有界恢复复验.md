# QA-09 父清理启动前只读有界恢复复验

依据：[b552237目标复验](../audit/QA-09-b552237合同await微任务分界R0-R1目标复验-2026-10-10.md)。旧R0父清理在StartBuild前的batch-get-projects网络错误中失败；精确补偿及关闭恢复PASS，原R0仍FAIL，R1 NOT RUN。此次只修复新执行的只读入口，不追溯升级旧记录。

## 实现边界与本地矩阵

`runFixture` 在任何项目变更或StartBuild之前调用 `readPreStartFixtureOperation`，只允许 `sts:get-caller-identity` 与 `codebuild:batch-get-projects`。指定账号、指定项目及角色校验仍在读取成功之后执行；语义验证失败不重读。父、子共用原桥接器，原Plan/SQL/清理动作不重放。

每个逻辑读取最多3次调用（最多2次恢复），各次间固定250ms；每个逻辑读取总预算65000ms，CLI单次上限30000ms且受剩余预算限制。两个逻辑读取合计预算最多130000ms；调度或持久化可能导致实际墙钟超时，但超时结果不得进入项目变更/StartBuild。CLI仍 `AWS_MAX_ATTEMPTS=1`，连接/读取超时5/10秒。预算仅约束新增入口，既有已启动Build及日志读取有独立既定预算，不在此扩量。

| 条件 | 行为 |
| --- | --- |
| 明确CLI网络/读取超时、限流、RequestTimeout、ServiceUnavailable、NetworkingError | 预算内仅重读同一原操作；保留失败尝试 |
| AccessDenied、SSO/Token过期、未知/普通CLI_FAILED、无效JSON、输出上限、参数/资源错误 | 立即失败，不自动恢复 |
| 读取成功但错误账号/项目角色 | 立即失败，不重读、不修改项目 |
| create-project/update-project失败 | 仅一次原调用，禁止重试或继续StartBuild |
| StartBuild响应丢失 | START_OUTCOME_UNCONFIRMED，禁止重复StartBuild或猜Build ID |
| 已知Build读取失败 | 沿用原精确ID受控读取，不回到入口、不重放SQL |

每个尝试在CLI前持久化 `preStartReads` RUNNING；实际CLI仍逐次写入原 `operations`。失败保留allowlist错误元数据、耗时、exit/signal/字节数，不保存stderr、输入、Token或错误正文。新成功回执若经历入口失败，`preStartReadFailures>0`、`readGate=RECOVERED`、`originalReadGate=FAIL`；原失败尝试不覆盖。原readRecoveries字段仍仅统计已启动Build读取恢复，新增入口使用preStartReadFailures单独统计，不能混加为业务重试。整体成功必须有后续原Build及原结果验证，不由读取恢复单独决定。耗尽或终止错误仍原父FAIL，不能用补偿清理越过R1入口。

```sh
node --test scripts/qa09-prestart-read.test.mjs scripts/qa09-fixture-cli-observation.test.mjs scripts/qa09-cleanup-recovery.test.mjs scripts/qa09-nonactive-cleanup.test.mjs
```

矩阵使用独立临时目录的本地AWS CLI shim及虚拟时钟，无目标凭据/网络/SQL。验证原错误保留、三次上限、deadline、调度超时、拒绝扩预算、CLI关闭重试、只读恢复后原项目写入/StartBuild各最多一次，以及后续UNKNOWN不升级；原父完整清理失败矩阵继续运行。

## 新入口回执Gate

每个成功数据库桥接回执必须具备 `preStartReads`，两个逻辑操作顺序固定，分别attempt从1连续且≤3、结束PASS；所有失败必须是上述暂时错误且后续成功。`operations` 中这些实际调用位于首次项目变更/StartBuild之前，与尝试逐项对应，最多各3次；项目create/update及StartBuild分别最多一次。`preStartReadFailures`等于失败行数，若非零则成功回执的readGate必须RECOVERED、originalReadGate必须FAIL。无失败不能伪称生产网络故障恢复得到验证；shim证明属于本地证据。

父清理的observe/cleanup、子业务及独立空集桥接回执均按此审阅。若缺失新字段、顺序/次数/绑定不符、预算超时或失败被抹除，目标入口证明FAIL；不得回填旧b552237回执。若真实环境未发生暂时错误，只能记录“新入口/正常路径PASS，真实故障恢复未触发”。受控故障注入不得扩大至共享AWS服务，本轮不注入AWS网络或IAM错误。
