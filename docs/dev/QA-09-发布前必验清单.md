# QA-09 发布前必验清单

更新：2026-10-14。用户明确授权将三项不可得材料及其依赖项延期到发布前验收。本清单中的延期项均未验收，不因本次最小范围通过而变为 PASS；无需新建通道、角色或调整 IAM/KMS。

| 延期编号 | 现有材料/前提 | 发布前必须补验的结果 |
| --- | --- | --- |
| REL-MATERIAL-CLAIMS-01 | 现有可信来源签名、分别异常 exp/nbf/audience 的测试样本和有效对照 | 目标验签通道确实拒绝各异常 claims、接受有效对照，记录请求/结果并验证无副作用；非法签名拒绝不能替代 |
| REL-MATERIAL-NOTIFY-01 | 受控通知测试收件地址及明确发送范围 | 真实邀请、密码重置 API、权限、通知结果、Cognito 补偿；对应平台账号两项语义与浏览器旅程 |
| REL-MATERIAL-SETTING-01 | 可暂改并恢复的具体测试 Setting key | 真实更新、If-Match 版本竞争、读回、恢复；对应设置写入旅程 |
| REL-A2-01 | 现有真实许可证验签材料、现有可信签名固件包 | 独立许可证验签、自然 Active、设备生命周期、许可证完整生命周期、命令交付/结果、OTA 可信包/活动，以及依赖 Active/Maintenance 的 Media 完整成功路径；真实权限/隔离/非法转换校验仍需保留 |
| REL-QUEUE-01 | 可以精确限定并清理的现有队列测试路径 | 实际毒消息重试、DLQ 路由和自有消息恢复；直接调用已部署 Handler 的混合批次证据不能替代 |
| REL-PERF-01 | 发布性能验收窗口和既有受控测试资源 | 遥测/命令 P95、持续/混合/突发负载及恢复、冷启动和传输尾部；候选收益与仪表成本按发布决策需要核验 |

原八个完整领域合同的工作流、协议字段和附加约束继续由原校验器执行；本次最小范围正式回执不冒充原完整格式 PASS。发布验收应以对应原校验器、真实补验及已完成记录的可复用性共同汇总，不能只删除本清单中的延期标记。

本次最小范围继续保留真实证书轮换、鉴权隔离、适用服务器事务持久化、非通知语义、已执行的浏览器业务操作及布局/角色控制、归档/Replay/ESG/租约恢复和独立清理证明。历史 FAIL/UNKNOWN 不重写；未知计划不重启。

材料可由现有授权服务、设备或包提供，无需导出私钥、SecretString 或令牌。已有[运营最小材料清单](QA-09-运营最小材料清单.md)保持适用；本轮不发送运营消息。
