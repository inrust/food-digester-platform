## 新边界

| 阶段 | 边界与解释 |
| --- | --- |
| contract-load-delegate | 外层读取入口至Contract.findFirst公开query extension入口；包括delegate访问、参数构造、惰性提交与调度，不等于同步调用耗时 |
| contract-load-orm-prepare | 该公开扩展入口至其事务适配器queryRaw/executeRaw入口；包含规划、模型准备和调度，不能归因为纯compiler |
| contract-load-driver-query | 事务适配器入口至query/execute Promise结算；含驱动I/O和适配器解码，不能归因为纯数据库服务器执行 |
| contract-load-result | 适配器结算至loadContract返回/异常；含Prisma结果处理与不存在检查 |

四段共享原始墙钟/单调/CPU快照。CPU为PROCESS_ALL_THREADS，分段CPU不可叠加为compiler独占成本。边界捕获和完成日志成本归入下一段；最终段完成日志在公开读取边界之后，仍包含在应用总耗时中。允许5ms覆盖误差，不放宽旧客户端分段检查。contract-load及driver-query的includesConnectionWait=true，其余false不代表纯CPU证明。

所有权摘要只保留请求ID、modelEntries、driverDispatches及transactional。必须恰好一个Contract.findFirst扩展入口、一个属于此读取的事务查询，且四段与HTTP/REPORT请求完全一致。多个查询、根查询、重复摘要、缺失/错序/跨请求、失败或覆盖残差超限拒绝证明；业务原结果/异常不被观察器替换。事务对象仅包装queryRaw/executeRaw，BEGIN、commit/rollback、释放及超时仍由原适配器管理。
