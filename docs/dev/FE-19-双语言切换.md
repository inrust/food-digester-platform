## 1. 范围与交付物

| 交付物 | 实现 |
|---|---|
| i18n 框架集成 | 自研轻量模块（零新增运行时依赖）：`I18nProvider`/`useI18n`/`t(key, params)`；缺省 zh-CN；缺省 Context 即 zh-CN（旧测试/调用方零破坏）；缺失 key 运行时 warn + 回退 zh-CN → key；已在 App 组合根顶层挂载（[App.tsx](../../apps/admin-web/src/app/App.tsx)） |
| en/zh-CN 语言资源包 | [zh-CN.ts](../../apps/admin-web/src/i18n/resources/zh-CN.ts) / [en.ts](../../apps/admin-web/src/i18n/resources/en.ts)：通用/菜单分组/24 菜单项/错误映射；key 集 parity 锁定 |
| 语言切换组件 | Topbar 用户区 `language-select`（[Topbar.tsx](../../apps/admin-web/src/shell/Topbar.tsx)）；切换即时更新 + `<html lang>` 同步 |
| 缺失文案检测 | i18n.test.tsx：key parity（缺失 0）+ 非空断言 + **全量 UI 源码硬编码中文扫描 = 0**（注释剥离后 CJK 表意文字检测，窄白名单保留语言原生名） |
| 持久化 | localStorage（`fdp.admin.lang.v1`）；刷新/重新登录（重新挂载）保持；非法值回退 zh-CN |

## 2. 已迁移范围（全量 UI 硬编码扫描锁定为 0）

- 壳层：Topbar（面包屑/时区/通知/登出/语言切换）、Sidebar（菜单分组/项经 `menu.*` 键）、breadcrumb（Crumb 携带 i18nKey）
- 共享组件：ErrorNotice（**错误码统一映射表**：FORBIDDEN/UNAUTHENTICATED/NOT_FOUND/VERSION_CONFLICT/CONFLICT/VALIDATION_FAILED/INTERNAL_ERROR 两种语言；requestId 原文保留；服务端 message 为后端数据原文展示）、ConfirmDialog（原因/提示/确认/取消缺省文案）、CursorTable（加载/空态/过期/刷新/分页）、TimeText（日期按语言区域 `zh-CN`/`en-US` 格式化，时间仍按用户时区）
- 页面与控制器：`src` 下全部正式页面、controllers、state/router/menu；协议枚举、角色冻结显示名和用户输入业务数据保持原文。
- LocaleValue：数字、百分比和支持的单位统一使用 `Intl.NumberFormat`；未知协议单位只格式化数字并保留单位原文；日期继续由 TimeText 按用户所选时区输出。
