# QA-09 辅助采集分页批处理与入口复验

本手册补充[小批读取与总时限手册](QA-09-精确采集器小批读取与总时限复验.md)。`ebbcfc0` 的主关联55条通过，但本轮生成的辅助脚本有导入路径错误；另存修正后的首次真实初始化读取在40次调用、73秒时停止，只得到6/8条完整结果。真实分页通常还返回一页空终页，不能用“8×3=24次调用”代替分页预算。该轮R0阶段FAIL、R1未启动，原失败保留并执行同SHA关闭恢复。

新通用入口位于仓库 `scripts/`，显式从自身同级目录导入读取器，支持 `python3 -I` 和任意工作目录。下一轮不得复制旧审计目录中的内联辅助脚本或修改其封存字节。新入口只读取明确的8项初始化或12项负向请求，不创建身份、业务数据或Build。

## 固定预算与所有权

- 原读取器的120秒总时限、15秒单次CLI、40次调用、20页/查询、串行及零自动重试均保持。
- 请求按原顺序分为最多3个唯一Gateway request ID的一批；每批串行读取Gateway、Lambda阶段及由前两者唯一证明的至多3个Lambda invocation的REPORT。不扩大原时间窗或日志组。
- 使用已验证的UUID正则过滤模式；投影仅接受本批自有身份。校验唯一Gateway、唯一completion、Gateway/extended ID/status/invocation一致性和唯一REPORT；跨请求复用invocation失败。
- 负向GET仍校验客户端时间、GET/401及extended ID。Cognito在Lambda前拒绝时，必须读得自有Lambda事件0，不能伪造REPORT或SQL阶段。
- 在每查询两页的受控输入中，8项初始化18次调用、12项Lambda负向24次、12项Gateway拒绝16次；这不是目标AWS耗时承诺。超过原预算仍停止并保留PARTIAL、完整记录及当前批次已投影的部分Gateway/阶段/REPORT。
- 固定字段仅接受有限标量，剥离非白名单/异域事件；错误使用固定安全码。保留父/子原字节、采集器与reader SHA256。输出禁止覆盖，进程非0或任一Gate失败均不能继续R1。

## 下一新SHA入口

先人工通过GitHub Desktop推送本轮修复提交。核对同完整SHA的CI、默认关闭部署及19工件，重新生成输入和辅助清单；新清单绑定通用采集器、reader、独立校验器及原阶段检查器。先执行真实隔离入口检查：

```sh
python3 -I scripts/collect-qa09-auxiliary-phases.py --check-import
```

输出的modulePath必须是本仓库 `scripts/qa09_log_read.py`，哈希必须与推送SHA一致。入口矩阵必须包含真实CLI子进程、任意cwd、隔离Python、同名异域模块、两页/多页及部分失败；仅把脚本正文放进已导入模块的测试包装器不足以证明入口。

新前缀R0原业务与父子清理、独立空集完成后，保留四份主关联和原阶段Gate。辅助读取改用以下固定入口，路径均使用新轮原回执：

```sh
python3 -I scripts/collect-qa09-auxiliary-phases.py CHILD.json INITIAL.json --mode initial --expected-commit <完整新SHA> --parent PARENT.json
node scripts/check-qa09-auxiliary-read.mjs CHILD.json INITIAL.json PARENT.json
python3 -I scripts/collect-qa09-auxiliary-phases.py NEGATIVE-GET.json NEGATIVE.json --mode negative --expected-commit <完整新SHA>
node scripts/check-qa09-auxiliary-read.mjs NEGATIVE-GET.json NEGATIVE.json
```

独立校验器拒绝来源字节漂移、缺失/重复/异域记录、批次及调用页顺序错误、超预算、部分结果和嵌套载荷。它只证明辅助读取及归属；原初始化拓扑、负向无SQL、阶段阈值、业务和清理Gate继续独立执行。R0全部闭合才进入R1；R1仅切observer=true，之后原清理、独立空集与同SHA关闭恢复。失败先完成原清理和关闭恢复，未知启动不重放。

禁止用新入口重读旧失败轮并将其标为原整单元PASS；本轮只做离线修复，新的AWS辅助读取和完整对照等待新SHA。TCP/TLS不追加探针，独立设备验签、自然Active和邀请发送沿用未验收边界。
