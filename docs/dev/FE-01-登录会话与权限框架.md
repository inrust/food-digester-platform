# FE-01 登录、会话和权限框架

实现：[apps/admin-web/src](../../apps/admin-web/src/index.ts)；测试：[apps/admin-web/test](../../apps/admin-web/test)。

## 1. 范围与事实源

| 项 | 说明 |
|---|---|
| 任务 | FE-01（P1 / 管理后台前端），依赖 AUTH-01、CT-05、CT-06、DEC-012（均已交付/冻结） |
| 形态 | 框架无关的 TypeScript 模块（纯函数 + 注入端口）；React/Next.js 壳层绑定由 FE-02 落地，本任务不引入前端框架依赖 |
| 认证事实源 | IAC-01：User Pool 客户端 `AdminWebClient` 仅启用 `USER_SRP_AUTH`、`preventUserExistenceErrors`、软件令牌 MFA（池级 OPTIONAL，平台角色强制由账号策略收口） |
| 角色/权限事实源 | `@fdp/auth`（AUTH-01）封闭角色集与 `ActorContext` 语义；前端只读消费，授权唯一可信来源是后端 |
| 路由/菜单事实源 | `contracts/prototype-traceability.yaml`（CT-06）menus 的 routeId/label/pageState/roles，由契约一致性测试锁定 |
| 错误码事实源 | CT-05 `contracts/rest/error-codes.json`（401 `UNAUTHENTICATED` / 403 `FORBIDDEN`） |
| 功能边界 | 不实现 Cognito 账号运维页面；MFA_SETUP 为终止态提示，不实现 MFA 绑定向导 |

## 2. 模块组成

| 模块 | 内容 |
|---|---|
| `auth/srp.ts` | Cognito SRP-6a 客户端数学（纯 BigInt，无外部依赖）：临时密钥对、PASSWORD_VERIFIER 签名、Cognito 时间戳；私钥 `a` 仅内存持有 |
| `auth/cognito-idp.ts` | Cognito IDP JSON API 客户端（注入传输层）：InitiateAuth/RespondToAuthChallenge/REFRESH_TOKEN_AUTH/ForgotPassword/ConfirmForgotPassword/GlobalSignOut；`__type` → 封闭错误码（INVALID_CREDENTIALS 不区分用户不存在/密码错误，与防探测配置一致） |
| `auth/auth-flow.ts` | 登录编排：`login`（SRP 全程，密码不出现在任何网络调用）→ authenticated / mfa-required / new-password-required / mfa-setup-required；`submitMfaCode`、`submitNewPassword`、`forgotPassword`、`confirmForgotPassword`、`logout` |
| `session/jwt.ts` | JWT 载荷解析（仅显示与过期调度，不验签——验签在 AUTH-01 后端） |
| `session/session-store.ts` | `SessionStore` 端口 + 内存实现；V1 决策：Token 仅内存持有，不落 localStorage（防 XSS 窃取 Refresh Token），持久化变更需安全评审 |
| `session/session-manager.ts` | 会话生命周期：建立（ID Token 解析角色/scope，未知组、平台与 Customer 混绑、Customer 缺 scope 均失败关闭，与后端同口径）、过期前自动刷新、刷新失败清会话安全退出、刷新时角色变更即时生效、登出（本地清除优先，GlobalSignOut 尽力调用） |
| `api/http-client.ts` | 管理 API 客户端：Bearer 注入、CT-05 `Idempotency-Key`/`If-Match` 写头、401 → 强制刷新重试一次 → 仍失败清会话抛 `UnauthenticatedError`；403 → `ForbiddenError`（保留会话，携带 code/requestId 显示无权）；错误包络 `{error:{code,message,requestId}}` 解析 |
| `router/routes.ts` | 路由注册表：9 个菜单路由 + 4 个子页面（继承父菜单角色）+ `/login`、`/403` 公共页 |
| `router/guard.ts` | 路由守卫纯函数：allow / redirect-login（带 returnTo）/ redirect-home / forbidden / not-found |
| `menu/menu.ts` | 角色菜单派生：概览顶级项 + 设备管理/ESG管理/合约管理/平台管理 四组（原型分组），空分组隐藏；DEC-012 冻结显示名（PlatformSuperAdmin→平台管理员、PlatformOperator→设备操作员），未冻结角色回退角色代码 |

## 4. 对接说明（下游任务）

- **FE-02（壳层）**：绑定 `resolveRoute` 到路由器；`sessionManager.onClear` 订阅清会话事件跳回 `/login`；菜单渲染消费 `menuForRoles`；`Idempotency-Key`/`If-Match` 由 `createApiClient` 请求选项传入；危险确认等 UI 组件属 FE-02 范围；
- **FE-03～FE-19（页面）**：统一经 `createApiClient` 访问 API；`UnauthenticatedError` → 登录页、`ForbiddenError` → 无权界面、其余 `ApiClientError` 按 CT-05 code 展示；
- **部署配置**：运行时需注入 `region`、`userPoolId`、`clientId`（IAC-01 输出 `UserPoolId`/`UserPoolClientId`）与 API `baseUrl`；本包不含任何硬编码环境值；
- **FE-16**：权限复选框只读展示（DEC-012），角色显示名复用 `roleDisplayName`。

## 5. 未决风险

- SRP 客户端数学经测试内独立服务端全链路验证，但尚未与真实 Cognito User Pool 做联调；首次环境联调时若签名不匹配，优先核对 poolName 取值（UserPoolId 下划线后段）与 padHex 规则；
- Token 仅内存持有，页面刷新需重新登录；若产品要求刷新保持会话，需评审后引入安全的持久化绑定（`SessionStore` 端口已预留）；
- MFA_SETUP 终止态依赖管理员侧完成 MFA 绑定流程（属 Cognito 账号运维，FE-01 边界外）；
- 会话角色取自 ID Token 且刷新时才更新，组变更最长一个 Token 周期生效（与 AUTH-01 未决风险一致，即时吊销由 BE-RBAC-01 停用流程收口）。
