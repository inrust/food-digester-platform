## 2. 交付物

### 壳层（shell/）

| 模块 | 内容 |
|---|---|
| `AppShell.tsx` | 侧栏 + 顶部栏 + 内容区；移动端抽屉：汉堡打开、遮罩/Esc 关闭、关闭后焦点回收至汉堡按钮 |
| `Sidebar.tsx` | 角色菜单渲染；分组 `<button aria-expanded aria-controls>` 折叠；当前页 `aria-current="page"`；菜单项为真实 `<a href>`（键盘可用） |
| `Topbar.tsx` | 面包屑（分组 → 父菜单回链 → 当前页）、通知徽标（aria-label 含未读数）、用户区（用户名 + DEC-012 角色显示名 + 登出） |
| `breadcrumb.ts` | 面包屑纯函数：菜单页 [分组, 页面]，子页面经 `parentPath` 回链父菜单 |
| `shell.css` / `app.css` | 统一设计 tokens、页面/卡片/表格/表单/对话框样式；≤768px 侧栏抽屉，≤480px 单列与底部对话框 |

### 通用组件（components/）

| 组件 | 状态/能力 |
|---|---|
| `CursorTable` | 加载、空态、错误、stale + 数据时间；窄屏表格在自身容器横向滚动；调用方游标栈支持上一页/下一页 |
| `ErrorNotice` | 统一解析 CT-05 code/requestId；403 → 无权文案；409 `VERSION_CONFLICT` → “数据已被他人修改” + 刷新按钮（If-Match 冲突提示刷新） |
| `ConfirmDialog` / `Modal` | Portal 渲染；安全初始焦点、Tab/Shift+Tab 循环、Esc、焦点回收；打开时页面背景 inert + aria-hidden |
| `ScopeFilter` | Region/Subregion/Site 三级联动（选项按上游过滤，上游变更清空下游；DEC-011 语义）；显式 label + 重置 |
| `CustomerScope` | Customer 角色只读所属客户；平台角色下拉（选项由 API 注入） |
| `TimeText` | UTC 存储按顶部栏用户时区选择即时显示，偏好写入 localStorage；title 保留 UTC 原值，非法时区安全回退 |
| `FourAxisBadges` | DEC-010 四轴徽标（连接/生命周期/运行/授权），未知值 “—” |
| `Toast` / `useToastQueue` | info/success 自动消失，error 常驻（role=alert）且携带 code/requestId |

## 4. 对接说明（下游任务）

- **FE-03～FE-19 页面**：在 `AppShell` 内渲染；列表页用 `CursorTable`（rows/loading/error/stale/nextCursor），写操作用 `ConfirmDialog`（高危 requireReason），筛选用 `ScopeFilter`，时间用 `TimeText`，设备状态用 `FourAxisBadges`，反馈用 `useToastQueue`/`ErrorNotice`；
- **路由**：`AppShell.onNavigate(path)` 已接入 BrowserRouter；进入页面前经 FE-01 `resolveRoute` 判定；
- **样式**：`main.tsx` 引入 `shell.css` 与 `app.css`；响应式断言使用稳定 class/testid，并验证页面本身不产生横向溢出。

## 5. 未决风险

- 当前浏览器证据是本地 Chromium + HTTP mock，不等于目标部署环境的字体、CSP、Cognito 或真实 Admin API 联调；
- Toast 错误码/requestId 直接展示给最终用户，若 UX 评审要求收敛展示层级，由 FE-02 后续迭代调整。
