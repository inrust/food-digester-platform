# DEC-003 一次性证书包领取策略

> 2026-10-01 实施更新：DEC-003 已升级为 1.1.0：证书包仅含公开叶证书及 CA chain，禁止私钥；保留 24 小时与一次交付，新增双通道确认销包触发器。轮换完成由 DEC-026 双通道确认控制，既有首 Heartbeat Onboarding 激活不变。 当前协议见 [设备 API 文档](../api/README.md)；下文较早验收记录保留历史，发生冲突时以本次更新和当前契约为准。

DEC-003 已由业务方确认并升级冻结为 `1.1.0`。升级记录见 [DEC-003-upgrade-1.1.0.md](../../contracts/decisions/changes/DEC-003-upgrade-1.1.0.md)，原冻结记录保留历史。

## 冻结值

| 策略面 | 结论 | 消费任务 |
|---|---|---|
| 存储 | KMS 信封加密；`retentionSeconds=86400`；明文私钥永不落库 | SEC-01、BE-ONB-03、BE-CERT-02 |
| 领取 | `maxClaims=1`；服务端提交成功响应后立即销毁密文；重复领取拒绝 | SEC-01、BE-ONB-03、BE-CERT-02 |
| 丢失/不确定响应 | 不恢复旧包；吊销未确认新证书后重签 | SEC-01、BE-ONB-03、BE-CERT-02 |
| 销毁触发 | 成功领取；首次接入首个合法 Heartbeat；轮换双通道确认 | SEC-01、BE-ONB-03、BE-ONB-04、BE-CERT-02 |

## 可执行契约

- [certificate-package-policy.json](../../contracts/security/certificate-package-policy.json) 是策略数据事实源。
- [certificate-package-policy.ts](../../contracts/security/certificate-package-policy.ts) 提供数据驱动查询。
- `pendingParameters=[]`，策略状态为 `frozen`；后续变更必须提升 DEC-003 和策略版本。

## 生产交付语义

- `preparePackageDelivery` 仅预留本次领取并解密返回，密文仍保留；并发或重复预留被拒绝。
- HTTP 适配器必须在成功响应实际提交后调用 `onCommitted`：确认交付、销毁密文，无需消费 Token。
- 若客户端未确认收到响应而重试，服务端把 `claimedAt != null && encryptedPackage != null` 识别为不确定交付，先通过 IoT Provider 吊销未确认证书并清理旧包，再签发新证书和新包。
- Onboarding 与证书轮换共用上述状态语义；确认和恢复操作均具备幂等边界与审计记录。
