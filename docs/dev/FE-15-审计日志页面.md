# FE-15 审计日志页面

实现：[apps/admin-web/src/pages/audit](../../apps/admin-web/src/pages/audit/AuditLogsPage.tsx)；测试：[audit-logs.test.tsx](../../apps/admin-web/test/audit-logs.test.tsx)。

## 1. 范围与事实源

| 项 | 说明 |
|---|---|
| 任务 | FE-15（P1），依赖 FE-02、BE-AUD-01（admin-audit-api.json，DOM-03 append-only） |
| 路由 | `/audit-logs`（扩展路由，CT-06 矩阵外，平台组菜单）；audit:read V1 仅 PlatformSuperAdmin/Auditor |
| 只读 | 契约仅两个 GET 端点（parity 断言无写路径）；页面无编辑/删除入口 |
| 脱敏 | DOM-03：写入时 sanitizeAuditPayload + 读取时再次脱敏；前端渲染前再兜底脱敏（纵深防御），字段名模式与 packages/observability parity 锁定 |
| 边界 | 不展示 CloudTrail/基础设施日志 |

### 任务清单同步

任务清单已同步冻结的 DEC-012@1.0.0：BE-AUD-01 的 V1 矩阵仅允许 PlatformSuperAdmin/Auditor，PlatformOperator 与 Customer 角色均**无 audit:read（403）**。服务层仍强制 actor.customerId 租户隔离作为纵深防御，前端路由仅对 SuperAdmin/Auditor 开放。

## 2. 交付物

| 模块 | 内容 |
|---|---|
| `AuditLogsPage`（/audit-logs） | 筛选（actorId/customerId/objectType/objectId/action/result/时间范围，datetime-local → UTC ISO）+ 键集游标分页；结果徽标（FAILURE 显著）；详情 Modal（requestId/reason/ip/userAgent + 脱敏前后值 JSON） |
| `audit-state.ts` | result 文案、SENSITIVE_KEY_PATTERN（镜像 observability，parity 锁定）、sanitizeForDisplay（递归兜底脱敏）、formatAuditValue |
| `audit-api.ts` | listAuditLogs（筛选 + 游标）、getAuditLogDetail——仅 GET，无写函数 |

## 3. 验收基准与仓库内证据

| 验收基准 | 测试 | 结果 |
|---|---|---|
| 筛选分页与时区 | 全字段筛选、用户时区转换、倒置区间失败关闭与游标分页 | 仓库内 PASS |

| 页面与契约只读 | DOM 无写入口；adapter 与 OpenAPI 仅 GET | 仓库内 PASS |
| 详情字段 | requestId、原因、IP、UA 与脱敏前后值渲染 | 仓库内 PASS |

验证命令：`pnpm lint`、`pnpm typecheck`、`pnpm openapi:check`、`pnpm test`、`pnpm check:admin-web-e2e`。结果只支持前三层。

## 4. 未决风险

- 值形态脱敏（PEM/Bearer/Onboarding Token）由服务端保证，前端仅做字段名兜底；如需前端值形态双保险可引入 @fdp/observability（当前 admin-web 无此依赖，避免新增依赖面）；
- 审计筛选的 objectType/action 为自由文本（契约无枚举），如后续冻结枚举可升级为下拉 + parity 锁定。
- Owner：Release Engineering；关闭条件：真实五角色、只读零写请求、敏感信息零泄露与清理回执通过独立 Gate；当前保持 NOT RUN / NO RECEIPT。
