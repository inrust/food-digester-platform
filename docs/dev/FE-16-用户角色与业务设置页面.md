## 1. 范围与事实源

| 项 | 说明 |
|---|---|
| 任务 | FE-16（P2），依赖 FE-02、BE-RBAC-01（admin-user-api.json）、BE-SET-01（admin-settings-api.json）、DEC-012 |
| 路由 | `/settings`（CT-06 矩阵内菜单，PlatformSuperAdmin/CustomerAdmin） |
| 标签页 | 平台角色/用户管理（user:read）、设备用户管理（device-user:read，嵌入 FE-09 页面）、业务设置（settings:read） |
| 角色纪律 | 封闭角色集（AUTH-01/DEC-012）；V1 权限矩阵固定只读（复选框 disabled）；PlatformOperator 界面名固定“设备操作员” |
| 密码纪律 | 邀请/重置均由 Cognito 生成临时凭证经邮件发送；表单无永久密码字段，响应不含密码材料 |
| 设置纪律 | 封闭 key 集四项；乐观锁 version（409 → 刷新恢复）；command.confirmation 确认方式 DEC-023 固定（UI 只读） |

## 2. 交付物

| 模块 | 内容 |
|---|---|
| `SettingsPage`（/settings） | 三标签页按权限可见（CustomerAdmin 仅设备用户）；平台用户列表（roleType/status/customerId/q 筛选 + 游标分页）+ 行操作（角色/Scope/停用/重置密码）；设备用户按 Customer/Region/Subregion/Device/status/keyword 筛选；邀请表单、只读 RBAC 矩阵及带乐观锁的业务设置编辑 |
| `settings-state.ts` / `contracts/settings/business-settings-v1.*` | ROLE_OPTIONS 与邀请/角色校验；四类业务设置使用 v1 JSON Schema 和前后端共享运行时校验器，返回 `/value/...` 字段路径、类型、范围、顺序、枚举及重复项错误；command.confirmation 保持只读 |
| `users-api.ts` / `settings-api.ts` | listUsers/inviteUser（体不含 password）/assignUserRoles/setUserScope/disableUser/triggerUserPasswordReset；listSettings/getSetting/updateSetting（{value, version}） |

### 高风险权限变更确认

角色整体替换与停用经 ConfirmDialog 明确确认（danger）；重置密码经确认且提示不接触密码。

## 3. 验收基准与证据（vitest + jsdom，14 例 + parity 覆盖）

| 验收基准 | 测试 | 结果 |
|---|---|---|
| 两类用户表字段与筛选 | 用户列表（邮箱/显示名/角色显示名/状态/MFA/客户/更新时间）+ 四条件筛选回调；设备用户标签嵌入（含筛选/重置） | ✅ |
| 权威拓扑筛选 | Region/Subregion/Device 参数进入正式 OpenAPI；服务端按 Customer scope 从 Device→Site 真值和 ACTIVE assignment 联合筛选；前端完整遍历设备游标生成选项 | ✅ |
| 邀请/重置不暴露密码 | 邀请表单无 input[type=password]；提交体快照无 password 键；邀请/重置提示“Cognito 临时凭证、不接触密码” | ✅ |
| 自我提权和越权明确错误 | 403 → ErrorNotice 无权界面（自我提权场景） | ✅ |
| 并发冲突可恢复 | 设置更新 409 VERSION_CONFLICT → 提示 + 刷新按钮回源 | ✅ |
| 固定协议项只读 | command.confirmation 无编辑按钮 + DEC-023 只读说明；RBAC 复选框全部 disabled | ✅ |
| 业务设置字段校验 | 四类 key 的共享 v1 Schema、合法样例、非法字段路径/类型/范围/顺序/枚举与后端最终裁决 | ✅ |
| 角色纪律 | 混绑校验（邀请/分配）；1~3 上限；Customer 角色 scope 必填 | ✅ |
| CT-06 锚点 | settings 页 BE-RBAC-01/FE-16 元素 ⇄ SETTINGS_COVERAGE 精确一致；RoleCode/SettingKey/status 枚举 parity | ✅ |
