# FE-18 耗材状态与更换申请页面

实现：[apps/admin-web/src/pages/consumables](../../apps/admin-web/src/pages/consumables/ConsumablesPage.tsx)；测试：[consumables.test.tsx](../../apps/admin-web/test/consumables.test.tsx)。

## 1. 范围与事实源

| 项 | 说明 |
|---|---|
| 任务 | FE-18（P2），依赖 FE-02、BE-CNS-01（admin-consumable-api.json）、BE-CNS-02（admin-consumable-request-api.json）、DEC-008 |
| 路由 | `/consumables`（CT-06 矩阵内菜单，device:read） |
| DEC-008 | 耗材类型封闭集合（CARBON_FILTER 碳包 / BIO_ADDITIVE 活性菌）；device-reported-only：未上报 null + remainingDisplay='unknown'（绝不默认 50%） |
| 申请状态机 | PENDING→PROCESSING→COMPLETED/CANCELLED；迁移 If-Match（version）+ 审计；complete/cancel 强制备注；跳级/重复处理/终态迁移 → 409 |
| 边界 | 不预测寿命、不直接联系客户、不做库存/派单；协议冻结前无“来自设备”入口（source 恒 ADMIN） |

## 2. 交付物

| 模块 | 内容 |
|---|---|
| `ConsumablesPage`（/consumables） | 耗材列表（Region/Subregion/Site/连接/关键字/阈值/类型筛选 + 搜索/重置；标准名称、百分比、observedAt/stale 徽标；联系方式点击后按权限展示）+ 更换申请（状态/类型/设备筛选；处理/完成/取消操作模态框；新建申请幂等提示） |
| `consumable-state.ts` | 封闭类型集与标准名称（parity 锁定）、REQUEST_ACTION_MATRIX、gateRequestAction（device:write）、thresholdLevel（DEFAULT_THRESHOLDS 10/30 暂定，页面 prop 由字典/配置驱动）、validateRequestNote、CONSUMABLE_COVERAGE（13 锚点） |
| `consumables-api.ts` | listConsumableStatus、list/create/process/complete/cancel ConsumableRequest（If-Match + 强制备注） |

### unknown/stale 纪律

remainingPercent=null 或 remainingDisplay='unknown' → 仅文本“unknown（未上报）”，**不渲染进度条**（DOM 断言）；stale → “数据过期”徽标。

### 联系方式纪律

联系人使用同一授权列表响应的 contact（点击后展示，无额外网络请求）；无权限角色（Auditor/CustomerViewer）响应即 null——页面与网络均不含号码（DOM 全文负向断言）。

## 3. 验收基准与证据（vitest + jsdom，8 例 + parity 1 例）

| 验收基准 | 测试 | 结果 |
|---|---|---|
| 列/筛选/三段流程覆盖 | 列表列与七条件筛选回调 + 重置；申请时间/状态列；PENDING/PROCESSING/终态动作按矩阵渲染 | ✅ |
| stale/unknown 清晰 | unknown 无进度条 + stale 徽标；分级边界（9/10/30/31）+ prop 覆盖 | ✅ |
| 非法跳级 | 矩阵不渲染跳级按钮；409 CONFLICT（跳级/重复处理）错误呈现 | ✅ |
| 重复提交 | 创建幂等 replayed → “幂等返回现有记录”提示；inFlight 防重复 | ✅ |
| 无联系人权限不含号码 | contact=null 时 DOM 全文无号码（初始与点击后均断言） | ✅ |
| CT-06 锚点 | device-consumable 页 13 元素 ⇄ CONSUMABLE_COVERAGE 精确一致；枚举 parity | ✅ |

当前证据命令：`pnpm exec vitest run`、`pnpm --filter @fdp/admin-web exec tsc --noEmit`、`pnpm exec vitest run apps/admin-web/test/contract-parity.test.ts`。

## 4. 未决风险

- 展示阈值（10/30）为暂定值：页面接受 `thresholds` prop（字典/配置驱动），容器接线后无需改页面；
- 耗材列表无游标参数（契约未定义分页），大列表依赖服务端截断策略；
- 联系方式为列表响应内嵌（无独立 contact 端点），“点击加载”为纯展示层延迟。
