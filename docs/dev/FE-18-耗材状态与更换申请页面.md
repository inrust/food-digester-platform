实现：[apps/admin-web/src/pages/consumables](../../apps/admin-web/src/pages/consumables/ConsumablesPage.tsx)；测试：[consumables.test.tsx](../../apps/admin-web/test/consumables.test.tsx)。

| 项 | 说明 |
|---|---|

## 2. 交付物

| 模块 | 内容 |
|---|---|
| `ConsumablesPage`（/consumables） | 耗材列表（Region/Subregion/Site/连接/关键字/阈值/类型筛选 + 搜索/重置；标准名称、百分比、observedAt/stale 徽标；联系人点击后独立加载）+ 更换申请（状态/类型/设备筛选；处理/完成/取消操作模态框；新建申请幂等提示） |
| `consumable-state.ts` | 封闭类型集、申请状态机、thresholdLevel；将 `alarm.thresholds.CONSUMABLE_REMAINING_PERCENT` 的 warning/major 映射为 low/mid，并携设置版本或 NOT_AUTHORIZED/MISSING/INVALID/LOAD_FAILED 显式回退来源 |
| `consumables-api.ts` | listConsumableStatus、getConsumableContact（单设备按需）、list/create/process/complete/cancel ConsumableRequest（If-Match + 强制备注） |

### unknown/stale 纪律

remainingPercent=null 或 remainingDisplay='unknown' → 仅文本“unknown（未上报）”，**不渲染进度条**（DOM 断言）；stale → “数据过期”徽标。

### 联系方式纪律

状态列表 DTO、数据库 relation 与 OpenAPI Schema 均不读取或返回联系人。点击单台设备后才调用 `getConsumableContact`；仅 PlatformSuperAdmin、PlatformOperator、CustomerAdmin 可读，未授权 403，Customer 跨租户和不存在设备统一 404。测试锁定未点击前列表响应、网络请求和 DOM 均无号码，生产日志另受 sensitive sink Gate 约束。

## 4. 未决风险

- 耗材列表无游标参数（契约未定义分页），大列表依赖服务端截断策略；
- 默认 10/30 只在设置缺失、非法、无权限或加载失败时使用，页面必须同时展示回退原因；不将其伪装为已配置值。
- 目标 AWS 联系人 403/404、跨租户和零泄露回执仍为 NOT RUN / NO RECEIPT。
