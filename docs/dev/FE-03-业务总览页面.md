# FE-03 业务总览页面

实现：[apps/admin-web/src/pages/dashboard](../../apps/admin-web/src/pages/dashboard/DashboardPage.tsx)；测试：[apps/admin-web/test/dashboard.test.tsx](../../apps/admin-web/test/dashboard.test.tsx)。

## 1. 范围与事实源

| 项 | 说明 |
|---|---|
| 任务 | FE-03（P2 / 管理后台前端），声明依赖 FE-02、BE-DASH-01、FE-12、FE-18 |
| 依赖偏差说明 | FE-12/FE-18 尚未交付：卡片命令的“白名单 + 确认 + 结果”组件与耗材展示组件在本任务以可复用组件先行交付（`DeviceCommandActions`、`ConsumableGauge`），FE-12/FE-18 直接复用，不重复实现 |
| 数据事实源 | BE-DASH-01 `GET /admin/dashboard/overview`（`getDashboardOverview`）；Customer scope 由后端强制 |
| 命令事实源 | CT-04 `command-catalog.json`（快捷动作 START/STOP/REBOOT 均非高风险）；提交走 BE-CMD-01 `createDeviceCommand`（`Idempotency-Key` + `timeoutSec`） |
| 耗材事实源 | DEC-008 冻结策略（名称 碳滤网/生物添加剂、阈值 20%/15%、unknown 不伪造百分比、stale 标记），契约测试锁定 |
| 拒绝原因 | BE-DASH-01 `denyReason` 枚举文案全覆盖（契约测试锁定） |
| 功能边界 | 不展示 AWS 运维指标；卡片不含高风险命令（高风险需确认凭证，属 FE-12 命令页）；OTA 升级仅跳转 `/ota/campaigns`（FE-13） |

## 2. 交付物

| 模块 | 内容 |
|---|---|
| `pages/dashboard/types.ts` | 总览响应类型（镜像 OpenAPI） |
| `pages/dashboard/dashboard-state.ts` | 纯逻辑：快捷动作模型（服务端目录缺失按 UNKNOWN_COMMAND 失败关闭）、耗材展示模型、授权分布/告警级别/连接质量文案 |
| `pages/dashboard/DashboardPage.tsx` | 页面：指标卡（有效合约/设备总数+授权分布/在线数+在线率/今日估算碳减排 kg/能耗 kWh/处理量 kg）、数据基准时间（generatedAt）与 ESG 统计日（UTC）、最新告警（5 条）、设备卡片（≤10，ID/SN/别名/固件/连接质量/四轴徽标/两类耗材） |
| `pages/dashboard/dashboard-api.ts` | `fetchDashboardOverview` + `createDashboardCommandSubmitter`（幂等键 + 300s 超时） |
| `components/DeviceCommandActions.tsx` | 卡片命令组：白名单按钮、denyReason 展示、ConfirmDialog 确认、提交后显示“已受理（commandId），等待设备执行（Pending）”；失败内联 code/requestId |
| `components/ConsumableGauge.tsx` | 耗材条目：unknown 显示“—”不画进度条、stale 标“数据过期”、低于阈值 warn |

## 3. 验收基准与证据（vitest + jsdom）

| 验收基准 | 测试 | 结果 |
|---|---|---|
| 10 设备 Fixture 与指标/卡片值一致 | `10 设备 Fixture`：指标卡逐项断言（含授权分布、在线率口径、单位 kg/kWh、统计日与数据基准时间）+ 10 张卡片字段抽查（别名/SN 回退、固件、信号） | ✅ |
| 非法状态/无权限动作不可提交并显示原因 | `denyReason 展示`：DEVICE_SUSPENDED_RESTRICTED/FORBIDDEN 按钮禁用 + 原因文案；`quickActionsOf` 目录缺失 UNKNOWN_COMMAND 失败关闭 | ✅ |
| 命令提交后显示 Pending 而非“成功” | `命令提交`：确认对话框（明确“不代表执行成功”）→ 提交 → “已受理…（Pending）”；断言不含“成功” | ✅ |
| 空数据和部分失败可读 | `空数据可读`（0 指标/暂无设备/暂无活动告警）；提交失败内联错误（code/requestId）；页面 403 → 无权提示 | ✅ |
| 不展示 AWS 运维指标 | 页面仅渲染契约内字段（类型级约束 + 无 AWS 字样文案） | ✅ |
| 角色隔离 E2E | 属 QA E2E 范围；前端可见性由 FE-01 角色矩阵测试覆盖，scope 强制在后端 | 记录为边界 |

当前证据命令：`pnpm vitest run apps/admin-web/test`、`pnpm --filter @fdp/admin-web typecheck`、`pnpm verify`。任务文档不固化易漂移计数。

## 4. 对接说明

- **FE-12**：复用 `DeviceCommandActions`（或同源 `quickActionsOf` 模型）；高风险命令的确认凭证（confirmText/TTL）不在本组件范围；
- **FE-13**：卡片“升级”统一 `onNavigate('/ota/campaigns')`；
- **FE-18**：复用 `ConsumableGauge` 与 `consumablesOf`；
- **集成层**：`fetchDashboardOverview(api)` 装载，`state` 三态（loading/error/ready）驱动 `DashboardPage`。

## 5. 未决风险

- “较昨日/峰值功率/本月累计”等原型副指标无 API 来源（CT-06 未映射），未展示；如需应由 BE-DASH-01 扩展契约；
- 连接质量“强/弱”分级无冻结阈值，当前展示原始 networkType + signalStrength；如需分级须先立决策；
- 卡片命令结果仅为提交受理态；执行进度轮询/刷新策略由 FE-12 命令页与 QA 收口。
