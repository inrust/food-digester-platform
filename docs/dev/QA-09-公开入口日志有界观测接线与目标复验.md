# QA-09 公开入口日志有界观测接线与目标复验

已实现自有 opaque boundary 桥接、一次有界摘要及默认关闭的 Admin/配置/部署/精确采集器接线。本轮是本地实现及受控入口验收，尚未部署新代码，不证明目标开销、compiler归因或P95收益。[实施报告](../audit/QA-09-公开入口日志有界观测实施验收-2026-10-11.md)、[证据](../audit/evidence/qa-09-observer-cost-implementation-2026-10-11/)。历史[设计方案](QA-09-公开入口与恢复后日志预算分界方案.md)及其封存保持原字节。

## 接线与范围

| 层 | 实现 |
| --- | --- |
| Runtime | `FDP_CONTRACT_OBSERVER_COST`，默认false，严格true/false；true要求test/pool1/engine/preconnect/detail/public全成立 |
| CDK | `enableQa09ContractObserverCost`，默认false；直接Stack构造与context解析均校验依赖，仅ApiFn接收环境变量 |
| GitHub Actions | `contract_observer_cost`，默认false；push强制false，手动输入精确绑定expected_commit和运行ID |
| Admin | `initialize`→`createAdminContractHandlers`→`updateContract`→原事务内`observeContractLoad(work, enabled)`；JSON/JWT/账号状态及授权仍先于合同读取 |
| 桥接 | observability内部读取自有boundary WeakMap；外部只有opaque scope及固定边界枚举，不导出snapshot或Prisma/compiler内部对象 |
| 摘要 | `data-path.contract-load.observer-cost`，schemaVersion=1；原load及ownership日志之后尝试一次，不递归测量自身 |
| 采集 | normal/exact共用`qa09_observer_cost.py`投影；仅固定字段与最多4段，不保存SQL/DTO/参数/结果/动态错误 |
| Gate | `--observer-cost`要求唯一COMPLETE摘要；缺失、重复、错Gateway/Lambda/operation/时间、降级或越界不升级PASS |

每trace只认第一个合同load；关闭入口不创建scope、记录或额外时钟/CPU读取。公开调用同步返回原对象，不读取then、不新增await/SQL/事务/pool/重试。Q点增加固定`publicOutcome=RETURNED|THREW|NOT_OBSERVED`，区分同步抛出和原调用返回；不伪造ADAPTER_CALL_RETURNED。

复用原D/R/M/E共享边界，记录P/Q同步调用和原合同phase输出区间：D→P前缀、P→Q公开调用、Q→R返回尾、M→E恢复后。只将完整包含的非重叠输出区间归入一段；跨段AMBIGUOUS、缺边界UNRESOLVED、窗口外OUTSIDE。终态日志在E之后，不能按phase名从恢复后窗口扣除。CPU为PROCESS_ALL_THREADS，输出CPU另列，禁止CPU相减；`unattributedWallUs`仅为未归属墙钟界限，不是模型/compiler纯成本。

最多64区间（外层公开调用先预留名额）、4段、完整JSON≤4096字节、1次摘要输出尝试。没有全局请求map；scope WeakMap键随原frame释放，trace只保留当前有界状态，关闭后停止计量。自身时钟/CPU/簿记故障不替换业务值或错误。TRUNCATED、PROBE_FAILED、FOREIGN_SCOPE、REENTRANT、OUTPUT_FAILED、OWNERSHIP_INVALID、DUPLICATE_PUBLIC_CALL、MISSING_BOUNDARY、AMBIGUOUS均降级，所有残差为null。原日志仍按原路径交付；摘要sink失败不重试，由采集器保留NOT_OBSERVED/PARTIAL。

真实JSON.stringify/redaction/sink调用已在本地入口验证，console/pg或身份来源仍为受控测试适配器；同步返回不能证明stdout/CloudWatch已交付。摘要本身及观察簿记成本仍计入原始load/API/Lambda整体耗时，目标复验必须保留这些原始值。

## 新SHA目标序列

本轮不执行该序列。代码提交后由人工通过GitHub Desktop推送，再用实际完整SHA生成新输入，禁止把历史设计/受控矩阵当新版本工件回执：

```sh
node scripts/analyze-qa09-contract-observer.mjs --prepare <完整新SHA> <新输入文件.json>
```

1. 核对同SHA CI、默认关闭部署及19实际ZIP，实际`contractObserverCost=false`。保持ApiFn512MiB/reserved12/pool1、DB静态63≤70、并发≤6、6基线/最多12独立PATCH，不扩容、不重启资源造冷。
2. R0手动部署固定engine/preconnect/detail/public=true、**account_read_candidate=true**、`contract_observer_cost=false`、rollout_phase=immediate。expected_commit必须是实际同SHA；不能沿用原账号候选false→true对照输入。
3. R0新前缀业务、自然冷、原父子清理、独立空集、预算及阶段Gate闭合后才进入R1。原未知StartBuild、SSO余量、清理恢复规则沿用[既有复验手册](QA-09-合同公开运行时接缝与自然冷对照复验.md)。R0采集不加`--observer-cost`，必须没有新增摘要。
4. R1保持全部输入相同，仅`contract_observer_cost=true`，使用另一新前缀。PATCH normal/exact采集及阶段检查增加`--observer-cost`；审计GET保持原采集方式。摘要必须关联原Gateway/integration Lambda/operation及原时间窗，COMPLETE之外保留降级。
5. 每组manifest固定`requireContractLoadSplit/requireContractLoadDetail/requireContractAwaitCheckpoint/requireContractPublicBoundaries/requireContractObserverCost=true`，inputs明确`contractObserverCost=false/true`。`readMatchedColdUnit`复核输入原字节、实际ApiFn revision/code/模式、19工件、清理、预算、摘要和自然冷；缺冷保留NOT_OBSERVED，不补样。
6. 原清理及独立空集闭合后同SHA恢复observer/public/detail/account/preconnect=false，engine沿用true。复核19工件、实际新旧开关、最终空集/预算和全部精确Build终态。
