# DB-02 事务、Repository 与并发版本基础

实现位置：[packages/database/src](../packages/database/src/index.ts)；集成测试：[db02.test.ts](../packages/database/test/db02.test.ts)。

## 1. 模块组成

| 模块 | 内容 |
|---|---|
| `client.ts` | `createPrismaClient(databaseUrl)`：Prisma 7 + `@prisma/adapter-pg`；测试用 `pglite-prisma-adapter` |
| `transaction.ts` | `withTransaction(client, fn)`：交互式事务，异常全量回滚；嵌套调用复用外层事务（以有无 `$connect` 判定，PGlite 适配器不支持 savepoint） |
| `repository.ts` | `scopedRepository`（强制 customerId）与 `platformRepository`（跨 Customer 显式管理接口） |
| `pagination.ts` | 键集游标（不透明 base64url，键 = 末条 id）；limit 默认 50、范围 1~100 |
| `errors.ts` | 语义化错误 + `mapDbErrorToHttp`（→ CT-05 状态/错误码） |
| `context.ts` | `runWithContext` / `getRequestContext`：AsyncLocalStorage 审计上下文（requestId/actorId/actorRole），事务内自动传播 |

## 2. 边界规则

- Customer 业务读写默认经 `scopedRepository`：缺 scope 抛 `ScopeRequiredError`（映射 403）；`create` 自动注入 customerId。
- `updateWithVersion` 禁止业务 `data` 改写 `id/customerId/version/deletedAt`；命中保留字段抛 `ReservedFieldMutationError`（400 `VALIDATION_FAILED`），原记录保持不变。
- 跨 Customer 查询只能经 `platformRepository`（命名即警示；调用方必须是平台角色且写审计，DOM-03 接入）。
- 乐观锁：`updateWithVersion(id, expectedVersion, data, scope)` 条件更新 + 自增；冲突抛 `VersionConflictError` → 409 `VERSION_CONFLICT`；不存在 → `RecordNotFoundError` → 404。
- 软删除：仅 `customers`/`sites`（`{ softDelete: true }`）；默认查询排除已删除；审计/历史表调用 `softDelete` 抛 `SoftDeleteNotSupportedError`。
- 本包不依赖 `contracts`（源码契约包无法被 tsc 消费），HTTP 映射值与 CT-05 常量保持一致由集成测试锁定。

## 3. 验收基准与证据（vitest，PGlite 真实 PostgreSQL）

| 验收基准 | 测试 | 结果 |
|---|---|---|
| 缺少 scope 的 Customer 查询无法执行 | `缺少 scope 的查询/写入被拒绝`（list/findById/create + 空串 customerId） | ✅ ScopeRequiredError → 403 |
| 版本冲突返回 409 | `版本冲突抛 VersionConflictError`，`mapDbErrorToHttp` = 409/VERSION_CONFLICT | ✅ |
| 事务失败不产生部分数据 | 单事务与嵌套事务回滚后行数不变 | ✅ |
| scoped update 不能迁移租户或改写保留字段 | `customerId/id/version/deletedAt` 更新被拒绝，原 Customer 下记录不变 | ✅ |
| 附加 | 跨 Customer 越权不可见、平台接口显式、游标分页不重不漏、非法游标 400、软删除排除/恢复、上下文传播 | ✅ |

## 4. 未决风险

- `pglite-prisma-adapter`（0.7.x）为社区适配器，与 Prisma 7.9 的兼容性以当前测试集锁定；升级 Prisma 时需复跑 db01/db02 集成测试。
- Repository 返回类型为 `Record<string, unknown>`（未按模型泛型化），BE 任务消费时如需强类型可再封装；当前优先保证边界与事务语义。
- 嵌套事务检测依赖 `$connect` 存在性这一内部特征，Prisma 大版本升级时需复核。
