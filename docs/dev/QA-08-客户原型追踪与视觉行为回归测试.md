# QA-08 客户原型追踪与视觉行为回归测试

依据任务清单 QA-08，直接读取 `contracts/prototype-traceability.yaml`，复用 CT-06 的源 HTML Hash、双向元素清单、正式 API 响应字段和路由校验。生产 React 页面及控制器在 Chromium 中运行，HTTP 被每用例独立的合成数据夹具接管，不读取 AWS 凭据。

## 运行

```sh
node scripts/check-prototype-traceability.mjs --json
node --test scripts/check-prototype-traceability.test.mjs scripts/prototype-regression.test.mjs
pnpm test:prototype-regression /tmp/qa08-local-prototype.json
pnpm verify
```

Gate 先校验上游追踪，再执行 12 页面 × 375/1440px 两种视口，共 24 用例。`scripts/qa08-bindings.mjs` 将全部 117 项 Adopt/Adapt 分配至 40 个有实际浏览器断言的行为组，将 11 项 Defer/Reject 分配至禁止或只读语义断言。新增、删减、重复、跨页面或错误处置绑定均导致失败。

`qa08-prototype.spec.ts` 在每个行为组的断言完成后才登记执行。覆盖 9 菜单入口、动态字段与主要表格列、Region → Subregion → Site → Device 联动清空、危险命令的错误/正确确认及取消零写入、配置发布确认入口、别名保存、证书轮换请求、耗材处理状态与按需联系人、合约创建及至少一个设备绑定、ESG 周期与导出、平台用户及设备用户表单。

危险命令和解绑等确认流程取消，不发送真实业务命令；证书请求、别名、合约绑定等写入仅作用于夹具。设置页禁止平台密码输入，设备用户密码按 DEC-004 独立契约保留。权限矩阵所有复选框禁用；不把只读展示误判为自由权限编辑。设备状态按连接、生命周期、运行、授权四轴验证；Unknown 耗材不得补造百分比条。媒体仅静态授权图片，禁止原型摄像头播放/停止按钮及实时 video 元素。

每用例使用随机 QA08 前缀和随机业务数值，断言比较夹具返回值。原型示例数据不作为业务预期常量。额外注入未映射字段 canary，页面不得显示；正式 API 来源正确性由 CT-06 Schema 校验保障。

## 语义快照与更新

`apps/admin-web/e2e/qa08-snapshots/` 保存 24 份 JSON，记录标题、列名、按钮名称/禁用状态、表单标签与四轴名称/值。随机前缀归一化，时间固定；异步请求收敛后采集。布局独立检查文档溢出、文字裁切及手机侧栏 Escape/焦点恢复。此方案比较信息架构和行为，未执行逐像素、字体或颜色一致性验收。

若经审查确认产品信息架构变化，可在本地生成新候选快照：

```sh
cd apps/admin-web
QA08_RUN=1 QA08_UPDATE=1 pnpm exec playwright test
```

审查快照差异并提交后，再执行根目录的 `test:prototype-regression`。更新快照运行不能作为回归 PASS；正式执行器强制清空更新模式，并拒绝更新模式回执。默认前端 E2E 与 QA-05 排除 QA-08，保持原有 30 / 90 执行数量。

## 回执与失败关闭

执行器核对 Playwright 报告、24 条独立执行轨迹、唯一前缀、实际覆盖组/禁止项/菜单、行为证明、清理、零未处理请求及快照 SHA-256。跳过、重试后通过、flaky、缺页、缺组、重复覆盖、外部请求、缺清理、快照更新或 Hash 不符均拒绝 PASS。17 项回执和绑定正负测试验证这些拒绝路径。

回执绑定 Git 基线及生产源码、认证源码、REST/追踪契约、源 HTML、依赖、脚本、浏览器测试、24 快照的 SHA-256，并检查运行期间未改变。随机前缀、独立 BrowserContext、finally 关闭上下文及临时输出清理保障隔离。失败写出 FAIL 回执。

## 修复与边界

回归暴露并修复管理页配置查看/更新确认入口、操作页设备别名维护入口；依现有权限矩阵控制，额外验证 Auditor 只读配置、CustomerViewer 无配置入口、CustomerAdmin 无设备别名写入口。合约详情两张表和 ESG 两张非空表使用既有横向滚动容器，解决 375px 下溢出。

本地 PASS 证明生产浏览器界面在合成 HTTP 响应下的原型追踪和行为，不能证明真实 Cognito、API/AWS IoT、S3 URL、设备或部署后的页面效果。真实 AWS 为 `NOT RUN / NO RECEIPT`，由已排定的 QA-09 验收。无新增依赖、数据库迁移、部署或远程推送。
