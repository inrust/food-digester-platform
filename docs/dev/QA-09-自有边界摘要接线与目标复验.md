# QA-09 自有边界摘要接线与目标复验

本轮将[离线分界](QA-09-after-queue与driver-prefix离线分界.md)中可由仓库自身持有的边界接入目标代码。复用 `FDP_CONTRACT_OBSERVER_COST`，默认 false；没有新增配置开关。当前仅本地实现与受控运行时验证，目标部署和新 SHA 对照尚未执行。[实施记录](../audit/QA-09-自有边界摘要闭环实施记录-2026-10-11.md)。

## 边界与预算

启用后的合同 load 摘要为 `data-path.contract-load.observer-cost` / schemaVersion=2，保留 schema1 的四个输出归属窗口，增加 `ownedBoundaries`。原 `beginContractObserverCost(true)` 的低层旧接口仍可产生 schema1；Admin 的 `observeContractLoad(work, true)` 明确启用 schema2。采集器兼容历史 schema1，但新 required Gate 禁止它替代新边界。

| 分区 | 起止自有边界 | 含义 |
| --- | --- | --- |
| checkpoint-phase-setup | 共享 checkpoint → after-queue phase 创建返回后的快照 | 自有 phase 创建及观测开销 |
| checkpoint-output-return | 上述快照 → 原 await-queue finish 回调返回后的快照 | 原回调输出及观测开销 |
| after-checkpoint-to-dispatch | 回调返回快照 → 原 DRIVER_DISPATCH | 合并引擎推进/调度间隔，内部归因未决 |
| repository-driver-setup | DRIVER_DISPATCH → 自有 bridge 完成 scope 归属查询后的标记 | 原 phase 初始化/关闭/日志和调用准备 |
| observer-public-bridge | bridge 标记 → 原 PUBLIC_ENTER | 自有桥接及测量准备 |
| public-callback-setup | PUBLIC_ENTER → 调用原 work 前标记 | 公开调用中、进入回调前的自有准备；不是整个公开调用 |

前三段之和精确等于共享 checkpoint→dispatch 的 afterQueueWallUs；第四、五段之和等于原 driver-prefix；第六段不能超过 public-call。新 Gate 将 afterQueueWallUs 与原 `contract-load-await-after-queue` 的整数毫秒 durationMs 比对，允许最多 1ms 的舍入差。自有标记不是 adapter/compiler 内部入口，不能把离线 adapter 包装端口迁入生产。

新字段仅含固定名称、整数微秒和固定范围声明。所有自有墙钟段**包含观测开销**，不扣 CPU 或日志成本；旧四窗口的输出归属/降级规则保持。关闭时不创建 scope，不为新边界增加时钟/CPU读数。开启时仍使用既有 checkpoint 微任务，不增加 await、then 消费、SQL、pool、事务、重试、强制让步或网络；原同步返回/Promise/错误保持。每请求最多64区间、4旧窗口+6自有段、4096字节、1次摘要输出尝试，摘要自身不递归计量。

缺失、重复、倒序、非法边界，测量失败、异域 scope、租约失配、输出失败/重入和限额均保留降级；缺失 checkpoint 时不得伪造零段。同步抛错不伪造 adapter-return；异步拒绝可能发生在原同步调用正常返回之后，摘要 COMPLETE 仅表示观测完整，不代表业务/事务成功。业务、版本冲突和清理 Gate 独立检查。

## 配置闭环

`workflow contract_observer_cost` → `resolveDeploymentInputs` → `enableQa09ContractObserverCost` → 唯一 ApiFn 环境变量 → `resolveContractObserverCost` → Admin handlers/updateContract → 原事务内 load → 有界摘要 → normal/exact 统一投影 → 阶段/匹配自然冷 Gate。

push 固定关闭；手动 true 仍要求 test、pool1、engine、preconnect、detail、public 全部成立。托管部署输入新增 `contractObserverSchemaVersion=2|null` 元数据，绑定同 SHA，不增加环境变量。实际配置验证继续要求唯一 ApiFn、512MiB/reserved12/pool1、revision/code/19工件精确一致。仅声明 schema 元数据不能替代实际 schema2 摘要。

## 新 SHA 执行顺序

本轮不执行云端序列。按 AGENTS.md 由人工通过 GitHub Desktop 推送本地提交后，以实际完整 SHA 生成新文件：

```sh
node scripts/analyze-qa09-contract-observer.mjs --prepare <完整新SHA> <新输入.json> --owned-boundaries
```

1. 同 SHA CI、默认关闭部署、19实际ZIP和配置先闭合。保持 DB 静态63≤70、ApiFn512MiB/reserved12/pool1；业务并发≤6，6次基线、最多12次独立PATCH。不得扩容、重启资源造冷或补采样。
2. R0：engine/preconnect/account/detail/public=true、observer=false，rollout_phase=immediate；新前缀业务、自然冷、原父子清理、独立空集、预算与阶段全部闭合。采集器不加新 required 参数，必须没有摘要。
3. R1：保持全部输入相同，仅 observer=true，使用另一个新前缀。PATCH normal/exact 采集和阶段检查同时增加 `--observer-cost --owned-boundaries`；审计 GET 不要求合同摘要。
4. 两组 manifest 均含 `requireContractLoadSplit/requireContractLoadDetail/requireContractAwaitCheckpoint/requireContractPublicBoundaries/requireContractObserverCost/requireOwnedBoundaries=true`，inputs 明确 observer false/true。旧 manifest 缺新要求不能用于新 Gate。
5. R1 原清理与独立空集闭合后，同 SHA 关闭恢复 observer/public/detail/account/preconnect=false、engine=true。复核19工件、实际配置、最终容量/空集、归档版本和全部精确自有 Build 终态。任何失败仍优先清理/关闭恢复；未知启动不重放，沿用[既有手册](QA-09-公开入口日志有界观测接线与目标复验.md)的 SSO、单次启动、有界恢复和清理规则。

```sh
python3 scripts/collect-qa09-contract-correlation.py <原子流程.json> <R1新PATCH关联.json> --observer-cost --owned-boundaries
python3 scripts/collect-qa09-contract-correlation.py <原子流程.json> <R1新精确PATCH关联.json> --observer-cost --owned-boundaries --exact-from <原PATCH关联.json>
node scripts/check-qa09-contract-phases.mjs <原子流程.json> <PATCH关联.json> <审计GET关联.json> <新阶段.json> --account-phases --client-preparation --client-split --engine-cpu --runtime-assembly --authenticated-preconnect --contract-load-split --contract-load-detail --contract-await-checkpoint --contract-public-boundaries --observer-cost --owned-boundaries
node scripts/analyze-qa09-contract-observer.mjs <R0阶段manifest.json> <R1阶段manifest.json> <新对照.json> --owned-boundaries
```

独立采样按原规则增加 `--cold-sampling`，不得混配基线/采样冷样本。normal/exact 同用闭合白名单，丢弃顶层/嵌套任意业务字段；新 Gate 要求同请求 Gateway/Lambda/operation/时间窗唯一 COMPLETE schema2。缺摘要、旧 schema、错误守恒或归属保留 PARTIAL。

目标只能证明新分段观测及输入相容，不能自动证明 compiler 独占成本、模型成本后移或 P95。TCP/TLS 继续独立诊断；本轮不追加探针，不把本机证据归因为网络节点。
