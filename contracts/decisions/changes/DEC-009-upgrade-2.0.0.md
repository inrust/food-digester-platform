# DEC-009 图片预览与关联留档升级

2026-11-06，Anray 确认设备图片接口设计，并授权 P0 的 IMG-01 至 IMG-04。DEC-009 从 1.0.0 升至 2.0.0，契约包从 0.15.0 升至 0.16.0，登记版本为 1.38.0。

设备本地显式启用 live-image-v1，并由服务端按原始 deviceId 白名单准入，两项均默认关闭。旧设备沿用归档 Media 接口与手动刷新入口。新预览走五个 REST 接口，设备查询 5 秒，上传与页面读取各 2 秒，租约 30 秒，每 10 秒续租，最新帧最多有效 10 秒。归档照片通过上传会话 triggerRef 关联源事件或告警消息。

P0 将单设备同时查看租约上限定为 16，以使设备状态记录、并发 CAS 和负载都有明确边界。超出返回 429，已有租约续租仍放行。这是实施新增的有界参数，后续修改随策略版本变更。共享存储及授权失效协议见 [并发设计](../../../docs/dev/IMG-03-图片预览临时存储与并发设计.md)。

旧请求不带 triggerRef 时只返回旧会话字段。新请求允许 200 重用与 409 已登记，triggerRef 只在关联请求响应中出现。旧响应验证器对封闭响应、新状态码的兼容风险由契约基线精确记录，客户端须在启用新能力前使用对应版本。

消费者为 IMG-01 至 IMG-04、BE-MED-01、FE-06、FE-12、FE-14。业务后端和页面的消费在后续阶段交付，P0 只提供策略、契约、设计和本地模型验证。DEC-024 的大小、归档配额及预签名期限继续由其原版本约束。
