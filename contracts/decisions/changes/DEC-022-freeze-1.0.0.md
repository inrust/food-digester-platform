## 冻结值

- 密钥：AWS KMS 非对称 `RSA_2048` / `SIGN_VERIFY`，私钥不离开 KMS。
- 算法：`RSASSA_PKCS1_V1_5_SHA_256`；编码：`base64`。
- 规范载荷：`FDP-OTA-SIG-v1`，按 `model`、`version`、`packageType`、`sha256` 固定顺序逐行拼接，`sha256` 使用小写 hex。
- 信任根：部署环境创建并以 `OTA_SIGNING_KEY_ARN` 注入的 KMS Key；请求、包元数据、响应和审计均不得接受或输出信任根。

## 影响与验证

- 影响 BE-OTA-01～03、SEC、IAC 和 QA-02。
- 仓库固定 RSA 公钥/签名向量只用于契约回归，不是任何环境的生产信任根。
- 生产验签只授予 Admin API `kms:Verify`，签名权限留在独立固件发布流程。
