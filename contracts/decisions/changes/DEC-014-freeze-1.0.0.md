## 冻结值

- 退役确认窗口为 72 小时，以退役记录 `initiatedAt` 起算。
- 窗口内证书保持 Active，但只允许 Sync 和 Deactivate；其他 Device REST、业务 MQTT 发布/订阅和命令全部拒绝。
- 设备确认或管理员提前强制完成后立即撤证。
- 到期未确认时自动强制完成并立即撤证，审计结果记为 `UNCONFIRMED_TIMEOUT`。

## 影响与验证

- 影响：AUTH-03、DOM-01、BE-SYNC-01/02、BE-DEV-04、QA-06 和退役 OpenAPI。
- 必须补充可重复执行的超时评估器；重复执行不得产生第二次撤证或重复业务副作用。
- 回滚：不得恢复为无限期 Active；期限变化必须提升 DEC-014 版本并迁移尚未完成的退役记录。
