## 2. 方案 A 冻结内容

- 证书包存储成功时开始 24 小时首个合法 Heartbeat 硬截止，精确截止边界计入超时。
- 超时后内部 Onboarding 申请置为 `TIMED_OUT`，外部状态保持源协议三态并映射为 `REJECTED`，稳定原因为 `ONBOARDING_TIMEOUT`。
- 未确认新证书置为 `REVOKED` 并调用云端撤证，证书包密文立即销毁；云端撤证失败由评估器幂等重试。
- 设备回到既有 `PendingOnboarding`，不新增设备生命周期状态；超时证书的迟到 Heartbeat 失败关闭。
- 截止前证书包过期仍按 DEC-003 撤证重签；超时后不自动重签。再次 Onboarding 必须由业务方签发新 Token，并创建新申请；旧申请保留为超时审计事实。

## 3. 实施边界

- DEC-003 的响应不确定恢复仍可在截止前撤证重签；DEC-017 超时后不再自动恢复。
- 超时评估器只完成 Onboarding 失败处置，不分配 Customer/Site，不签发 License。
