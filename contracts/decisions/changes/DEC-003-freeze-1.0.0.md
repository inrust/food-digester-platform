## 冻结值

- KMS 信封加密保存证书包，`retentionSeconds=86400`。
- `maxClaims=1`；服务端提交一次成功响应后立即销毁密文。
- 响应不确定、包丢失或过期时，不恢复旧包；吊销未确认新证书后重新签发。

## 影响与验证

- 影响：SEC-01、BE-ONB-03、BE-CERT-02、Onboarding/Rotate OpenAPI。
- 兼容性：从无定量值的 fail-closed 策略升级为可执行冻结值；重复领取仍拒绝。
- 回滚：不得降回未决值；如需修改必须新增 DEC-003 版本并同步策略、契约和迁移说明。
