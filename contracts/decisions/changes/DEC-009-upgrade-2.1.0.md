# DEC-009 取消逐设备预览白名单

2026-11-11，按用户提出的流程简化要求，设备本地继续管理 `live-image-v1`。云端复用既有证书、客户归属、生命周期和运行状态，授权查看者通过租约按需查看。符合条件的设备在无人查看时收到 `200 IDLE`。管理员沿用现有激活和分配流程。

授权变更在 PostgreSQL 写事务提交前关闭已有预览流并递增代次。设备重新符合条件后，从最新授权上下文创建新租约和 streamId，旧租约与旧帧失效。旧白名单表保留以支持部署兼容和回滚，新运行代码不再读取或依赖其记录。

部署需要使设备 API、平台 API 和数据库权威写入口使用同一版本。切换完成后核对无白名单记录的合格设备返回 `IDLE`，有租约时能上传并读回同一张图，再验证证书、客户归属及设备状态变化使旧流失效。
